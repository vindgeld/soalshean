General Setup

Behaviour & Accessibility

Each submitted attempt is POSTed here as JSON (e.g. a Google Apps Script) so you can collect results from all participants. Note: answers and settings are visible in the exported file, so don't use it for high-stakes exams.

Score Ranges & Grading

Use {score} in a message to show the percentage. Define messages based on the percentage score. E.g., 0-50% = "Try again", 51-100% = "Passed!". (Ensure ranges don't overlap).

End Screen Behaviour

Participant Attempts

Note: In the exported Standalone App, logs are saved to the participant's local browser storage. For centralized tracking, set a Results Webhook URL in Settings. Previews are never recorded.

Bulk Import Questions

Format: The first line is the question (a single line becomes a blank question). Following lines are options. Prefix correct option with '*'. Blank line separates questions.
